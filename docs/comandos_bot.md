# Comandos do Bot

| Comando | Status | Descrição |
|---------|--------|-----------|
| `/start` | Ativo | Saudação e instruções |
| `/cliente <nome>` | Ativo | Buscar cliente por nome |
| `/agendar` | Placeholder | Criar evento no Calendar |

## Ações automáticas

| Ação | Gatilho |
|------|---------|
| Classificar documento | Envio de foto ou PDF |
| Criar pasta no Drive | Cliente novo detectado |
| Registrar na planilha | Qualquer documento processado |
| Identificar cliente | Dados extraídos pela IA |
